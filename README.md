# JF Inventory - Sistema de Controle de Estoque Android

## 📱 Sobre o Projeto
Este aplicativo foi desenvolvido como parte integrante da Atividade de Extensão Universitária. O objetivo central é a digitalização e otimização do controle de inventário de hardware para pequenas assistências técnicas na região de Juiz de Fora - MG.

O sistema permite o registro, consulta e atualização de peças em tempo real, eliminando falhas de contagem manual.

## 🛠️ Tecnologias Utilizadas
* **Linguagem de Programação:** Kotlin
* **Plataforma:** Android Studio
* **Banco de Dados:** Firebase Realtime Database (Nuvem)
* **Arquitetura:** Baseada em componentes Android nativos
